💡 はじめに：「判断AI」ってなに？クリックで開閉

ChatGPT のような AI は、質問に文章で答えます。 いっぽう「判断AI」は、こちらが用意した選択肢の中から選び、どれくらい自信があるかを数字（確率）で返します。 文章は書かないかわりに、とても速くて安いのが特長です。

判断AIにできる質問は、次の3種類です。

  • はい／いいえ 「〜ですか？」に答え、「はい」の確率を返します。
  • 選択 いくつかの選択肢から1つ選び、それぞれの確率を返します。
  • 段階評価 「低い〜高い」のような段階のどこにあたるかを返します。

使いみちの例：問い合わせの振り分け、口コミの良し悪しの判定、迷惑メールの検出、AIエージェントの行動チェック など。

1お題をえらぶ

まずはサンプルを選んでみてください。文章と質問が自動で入ります。もちろん、あとから自由に書きかえてOKです。

2判定したい文章を入れる

AIに読ませたい文章です。お客さまからのメール、口コミ、チャットのやりとりなど、なんでもOK。

0 / 6000 文字

⚠️ 入力した文章は OpenRouter を通じて各AIの提供会社に送られます。個人情報や社外秘の情報は入れないでください。

3AIへの質問をつくる

判断AIには「何を判断してほしいか」を質問の形で伝えます。1回で最大5つまで同時に聞けます。 選択肢や基準の説明をていねいに書くほど、判断が正確になります。

4比べるAIをえらぶ

チェックを入れたAIすべてに、同じ文章・同じ質問を送ります（最大6つ）。

📊 結果

📖 結果の見方ガイド（用語集）クリックで開閉
確率（%）
AIが「この答えだと思う」度合いです。「はい 96%」なら、かなり自信をもって「はい」と考えています。50%前後は「どちらとも言えない」という意味です。
信頼度
選択や段階評価で、確率が1つの答えにどれだけ集中しているかを表します。高いほど迷いが少ない状態です。
スコア
段階評価で、確率をふまえた「平均的な位置」です。いちばん左の段階が 0 で、右に行くほど数字が大きくなります。
意見の一致
選んだAIたちが同じ答えを出したかどうか。分かれた質問は、AIにとっても判断が難しい（＝質問や基準の書き方を工夫する余地がある）ことが多いです。
応答時間
質問を送ってから答えが返ってくるまでの時間です。ネットワークの状況でも変わります。
費用・トークン
AIは文章を「トークン」という小さな単位に区切って読みます（日本語ならだいたい1文字＝1トークン前後）。判断AIは読んだ量（入力トークン）だけに料金がかかります。料金はドル建てなので、為替レート（欧州中央銀行の参考レート）で円に換算して表示しています。
品質を比べるコツ
正解がはっきりしている文章（例：明らかな迷惑メール）と、人間でも迷う文章の両方で試すと、AIごとの得意・不得意が見えてきます。

このページは OpenRouter の Decisions API を使ったサンプルです。 結果は毎回少しずつ変わることがあります。
